# Worth a Read
#
# A running list of things worth reading. One markdown link per line,
# followed by an em dash and a short note on why it is worth reading. To
# add an entry, append a line and push; the backend syncs it into the
# worth_a_read table on its next daily run, or immediately via the
# on-demand sync endpoint.
#
# Machine-read by the backend, so keep it to one link per line.

- [The C10K Problem](http://www.kegel.com/c10k.html) — old but still the clearest explanation of the concurrent-connections problem
- [Falsehoods Programmers Believe About Time](https://gist.github.com/timvisee/fcda9bbdff88d45cc9061606b4b923ca)
- [Reflections on Trusting Trust](https://www.cs.cmu.edu/~rdriley/487/papers/Thompson_1984_ReflectionsonTrustingTrust.pdf)
- [Linux Kernel Startup, Explained](https://internals-for-interns.com/posts/linux-kernel-startup/) — clear, well-taught walkthrough of the kernel's internals; great if OS week left you wanting more depth
- [HTTP/2 Explained](https://http2-explained.haxx.se/en/part1) — by Daniel Stenberg, author of curl; a genuinely clear account of how HTTP/2 was implemented
